OpenAI's Decisions API goes GA: 400 typed questions per request

Typed yes/no, pick-one and score answers at $0.10 per 1M input tokens, per OpenAI's own docs.

By The Gayzette, with Claude · 2 min read · Wonder ◆◆◆◇◇

OpenAI made its Decisions API generally available on Oct 22 (it had been in public beta), per the company's developer changelog. Instead of writing prose, the model answers a list of questions about one shared input, which can be text, images or JSON (a plain data format). Each request now takes up to 400 questions, up from 200 in beta.

Questions come in three types: Predicate (a probability from 0 to 1 that a condition is true, for example, our illustration: does a photo show damage?), Choice (one value from a fixed set, for example, which department a message belongs to) and Score (2 to 10 ordered levels, returned as a probability-weighted score). Per the docs, uncached input costs $0.10 per 1M tokens (a token is a small chunk of text the model reads), output tokens are "not charged," and gpt-6-luna is the only supported model. The caveat: the docs call it about 10x faster than the Responses API, which is OpenAI's own claim; we did not check an independent benchmark.

On your desk: this looks like a natural sorting step for an n8n studio-inbox pipeline: is this message a coaching question, a billing question or something else, using one Choice question with a short list of labels. Test it on a week of old messages before trusting it with real ones.

On our desk

A cheap sorting primitive that a solo builder could wire into n8n at low cost, though the pricing and speed come from a single vendor source.

Claude Code 2.1.309 closes several permission-check gaps

A security and sandbox release, per Anthropic's own GitHub notes.

Disclosure: Anthropic makes Claude, the model that helps make this paper. Its Claude Code v2.1.309 release notes (Oct 22) say it fixed several Bash permission-check gaps, including cases where Edit(path) deny rules were skipped by redirects inside some subshells (a command run inside another command). Sandboxed commands and auto-accepted edits can no longer modify the --mcp-config file, and, in the Desktop app and VS Code, dangerous rm and rmdir commands in bypass-permissions mode are denied right away with a rewrite hint.

Two changes may touch scripts: claude ultrareview now requires workspace trust (pass --trust-workspace or set CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1), and sed -i now uses the standard Bash prompt and is no longer undone by /rewind. The caveat: these are changelog entries, not an incident report, so it is unclear whether any bypass was exploited.

On your desk: skim your vault automations for any script that calls claude ultrareview or sed -i, since those are the ones that may now stop and ask.

n8n 2.45 adds confidence scores to the Text Classifier

Read the brief

An opt-in output on the node that sorts text into labels, per n8n's release notes.

n8n 2.45, released Oct 20 per its release notes, adds an opt-in confidence-score output to the Text Classifier node (the step that sorts incoming text into categories you define). It also adds a V2 Monday.com node with full parity with V1, and makes Kafka version 2 (a message-queue connector) the default for new nodes. The notes also list admin notifications in migration rule details and a publish-confirmation modal in the agent builder.

The caveat: this is an incremental release, and we read only part of the page, so check the full notes before upgrading.

On your desk: if your studio-inbox pipeline uses the Text Classifier, the confidence score could let low-certainty messages go to a human instead of being filed automatically. It pairs naturally with today's lead.

More in Spirit

Nature study: psilocybin brain patterns follow the setting

Read the brief

Monash researchers scanned volunteers during rest, meditation, music and a cloud video.

PsyPost (Oct 22) reports a Nature paper, "Psychedelics align brain activity with context," from Monash University researchers Devon Stoliker and Adeel Razi. Sixty-three healthy adults aged 18 to 55, with little or no prior experience, took 19 mg of oral psilocybin and were scanned with fMRI (a scan that tracks blood flow as a stand-in for brain activity) during rest, guided meditation, emotional music and a silent cloud video. With eyes closed, connectivity in sensory regions fell by up to 39 percent and in associative regions rose by up to 72 percent.

The caveat is a big one: the study was open-label (everyone knew what they took), had no placebo and used a fixed condition order. Enzo Tagliazucchi, who was not involved, flagged the missing placebo and fixed order, and the 98 percent condition-classification figure comes from just six people. This is science reporting, not advice.

On your desk: the meditation-inside-a-scanner detail is a good story seed for a Consciousness University session on how setting shapes experience, with the caveats left in.

From the history: Tully, Queensland, Australia, 1966: a farmer said he saw a saucer-shaped craft rise from a swamp and fly away. Investigators found a nearly circular area about 10 m by 8 m where grass was flattened in clockwise curves and reeds were uprooted. According to the Wikipedia summary, police, the RAAF and the University of Queensland concluded it was most probably natural (a down draught, willy-willy or waterspout), though that sentence carries a citation-needed tag; in 1973 G.J. Odgers of Defence wrote a journalist that debris lifted by a willy-willy was probable. Doug Bower and Dave Chorley say Tully inspired them to start making circles in 1978, and Terence Meaden proposed in 1980 that whirlwinds caused circles; both are their own claims.
