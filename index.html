Gemini's Computer Use tool leaves preview: an AI that works a screen

Google says its screen-driving tool is now generally available, with sandbox warnings attached.

By The Gayzette, with Claude · 2 min read · Wonder ◆◆◆◆◇

Google says its Computer Use tool is now generally available (GA, meaning out of preview and open to everyone) in both the Interactions and GenerateContent APIs, per its developer changelog entry dated Oct 30. The tool lets a Gemini model look at a screenshot and answer with the clicks, scrolls and keystrokes it would make. Think of a very patient intern who can see your screen but has no hands: it points, and your own code does the pressing.

Your code runs each action, for example with Playwright (a tool that drives a web browser), then sends back a fresh screenshot, and the loop repeats. The docs cover browser, mobile and desktop setups, and Python needs google-genai 2.7.0 or newer. The caveat: Google's docs say to run it in a sandbox or virtual machine because it "may contain errors and security vulnerabilities," and the check for prompt injection (a web page sneaking in instructions) is opt-in and off by default.

On your desk: a sandboxed browser agent could take over repetitive studio admin for Travis, like checking class-roster or registration portals, and it would make a tidy Skool lesson on an agent with a screen and guardrails. For Patrick's Claude-agent vault office it is a useful comparison: a helper that acts, but only inside a fenced yard.

On our desk

A tool that can operate any website or app means agents no longer need a special connector for every service, which is why GA matters for builders.

Anthropic adds a Usage and Cost Analytics API in beta

Disclosure: Anthropic makes Claude, the model that helps make this paper.

Anthropic's Claude Platform release notes, dated Oct 29, 2026, announce a Usage and Cost Analytics API in beta. You switch it on with the header analytics-usage-cost-2026-08-24, and two endpoints (web addresses a program can ask) at /v1/organizations/analytics/usage and /v1/organizations/analytics/cost report token usage (tokens are the word-sized chunks an AI reads and writes) and cost. The older Usage and Cost API and four Claude Enterprise Analytics report endpoints are now labeled legacy but still supported. Caveat: these are organization-level endpoints, and the release notes do not say which key type is required.

On your desk: have a vault agent pull weekly spend into a note, so you can see what each agent job costs, like a utility bill for the AI office.

NVIDIA's MonsterHouse is a talking Halloween haunt built on open models

Read the brief

NVIDIA's Hugging Face blog, dated Oct 30, shows MonsterHouse, an interactive projection where a voice agent chats with visitors, all running on one workstation. It uses a Bolt E4B response model (4-bit) with a personality trained on 5,000+ multi-turn conversations, plus Magpie TTS Zeroshot, which clones a voice from a short sample in seven moods. NVIDIA reports a median 1.70 seconds from speech to audio reply, and 0.72 seconds for cached responses.

Caveats: those speeds are NVIDIA's own, measured on pro-grade GPUs, and the post says the MonsterHouse code itself is not packaged for release; it points to the Nemotron Voice Agent framework instead.

On your desk: a template for a talking character, a seasonal fit today, and a seed for a Stacy-persona voice-bot experiment.

More in Spirit

Psilocybin grows new synapses in mice, separately from the trip signal

Read the brief

Also from earlier in the quiet week: UC Santa Cruz News released a study on Oct 22, published online Oct 15 in Nature Neuroscience, led by Yi Zuo. In mice, psilocybin made new dendritic spines (tiny bumps where brain cells connect) within 24 hours, fading over about three weeks in healthy mice. In stressed mice, a depression-like model, the surge was larger and loss of existing connections was halted.

The effect depended on 5-HT2A receptors in layer 5 pyramidal neurons. Restoring them restored growth without the head-twitch response; deleting them abolished growth but left the twitch intact, so the authors say the pathways are separable. Caveats: mouse data only, no sample sizes in the release, and head-twitch is a rodent proxy, not perception.

On your desk: the science behind why peak experiences might change the brain, for consciousness courses, with an honest mice-only label.

What is known
