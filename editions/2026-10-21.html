Anthropic opens a waitlist for Claude Duet, a text-it personal agent

A research-preview app that works in its own cloud computer, with every feature described by Anthropic itself.

By The Gayzette, with Claude · 2 min read · Wonder ◆◆◆◇◇

Anthropic has opened a waitlist for Claude Duet, a personal AI agent you message like a friend. Disclosure: Anthropic makes Claude, the model that helps make this paper. Per Anthropic's product page, live as of Oct 21, Duet is a research preview (an early version still being tested) that works on tasks in its own cloud computer, sends a morning brief and checks with you before sensitive actions.

Anthropic says it can use your Claude memory, skills and apps, plus "more than 6,000 connectors and plugins" (connectors are links that let an AI read or act inside other apps), and that it asks approval before sending messages or paying. The page names no separate price; it says background checks count toward your plan's usage limits. The waitlist is for Claude Pro and Max subscribers in the US (Team and Enterprise aren't included yet); Duet is a standalone iOS and Android app, and on a computer it opens at claude.ai.

The caveat: every feature here is Anthropic's own description, and the page itself warns the preview "may misread a thread or miscalibrate what's urgent, and it can miss something that arrives between checking in with you." We found no outside testing.

On your desk: think of Duet as a candidate assistant for the studio's admin pile, like scheduling reminders and drafting replies to families. If you get in, start with low-stakes errands and keep payments behind its approval step.

Malicious LiteLLM 1.107.0 on PyPI steals credentials, SafeDep reports

One version of a popular AI toolkit is reported to run credential-stealing code every time Python starts.

Security firm SafeDep reports that LiteLLM 1.107.0, a version of a popular Python toolkit linking programs to many AI providers, was published to PyPI (Python's public package library) with credential-stealing code. SafeDep says 1.106.2 and the 1.107.0 release candidates are clean.

According to SafeDep, a file called cook.pth runs on every Python start and targets SSH keys, cloud credentials, CI/CD secrets (passwords for automated build systems), browser passwords and AI provider keys, uploading them to a site it names. A second piece, sitecustomize.py, runs an hourly background task that executes downloaded code. SafeDep's indicators include those files in site-packages (where Python keeps installed packages) and requests to 169.254.169.254.

The caveat: this is SafeDep's own analysis, not independently confirmed, and the article has no remediation section.

On your desk: run `pip show litellm` in any environment behind your websites or AI tools. If it says 1.107.0, rotating the keys on SafeDep's target list is our inference, not its instruction.

More in AI

Recursive releases Flint, an open 39.8B-parameter coding model

Read the brief

Apache 2.0 weights and strong self-reported scores, but it needs datacenter-class GPUs.

Recursive has published Flint on Hugging Face, a mixture-of-experts model for coding agents. Mixture-of-experts means only a slice of the model, about 2.5B of its 39.8B parameters (its learned settings), wakes up for each token (a chunk of text) The weights are Apache 2.0, a permissive license.

Recursive's model page reports 54.9% on Terminal-Bench 2.1, 89.7% on SWE-bench Pro v2 and 74.2% on SWE-bench Verified, averaged over at least five attempts. It handles 262,144 tokens at once.

The caveat: every benchmark is Recursive's own, and the model needs one B300 or H200 GPU per copy for its roughly 80 GB checkpoint, which no laptop has. The page carries no release date.

On your desk: nothing to run locally today. If a hosted version appears, it could be a cheap coding helper for your web projects, tested on a throwaway repo first.

DeepSeek open-sources DeepInfer, its production inference engine

Read the brief

Apache 2.0 code for running one DeepSeek model, offline only, on specific chips.

DeepSeek has put DeepInfer on GitHub, which it calls the high-performance inference framework that powers its large-scale production services. Inference is the stage where a trained model answers questions, as opposed to learning. The code is Apache 2.0, a permissive license.

Right now it supports DeepSeek-V4.1-Flash and offline inference only, with no KV cache system (the memory that lets a model reuse earlier work) and no full serving stack. It supports NVIDIA SM100 GPUs and Huawei Ascend 950 NPUs (Huawei's AI chips), and needs Linux, GCC 13 or newer, Python 3.12, and CUDA 13 or CANN 9.2.

The caveat: performance claims are DeepSeek's own, shown in charts with no throughput numbers in the page text, and the repo shows no release date.

On your desk: low direct use for a solo builder, since you would need those chips. Treat it as a signal that open AI infrastructure keeps improving.

Spirit

Psilocybin in 12 Parkinson's patients tied to lower inflammation markers

A small, uncontrolled UCSF pilot in JAMA Psychiatry, reported by NPR via OPB.

NPR's Will Stone, republished by OPB, reports a JAMA Psychiatry pilot led by UCSF in 12 people with Parkinson's disease, designed to test feasibility and safety. Blood tests tracked five inflammation-related signaling molecules (proteins cells use to message each other) around two psilocybin sessions.

Levels were significantly lower than baseline and stayed lower one month after the last dose. A mitochondrial-stress marker (strain on the cell's power plants) improved right after dosing, not later. UCSF's Ellen Bradley called it "an initial biological signal to investigate."

The caveat: there was no control group, and participants knew they got the drug, so expectation could explain part of this. Aoife O'Donovan said the results need confirmation, and Charles Nichols of LSU, who was not involved, called it exciting but limited.

On your desk: a tidy example for a sketch or script about science headlines. The sturdy version is the small one: 12 people, no comparison group, a blood signal and not a cure.
