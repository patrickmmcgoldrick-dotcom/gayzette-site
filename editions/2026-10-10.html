Claude Managed Agents can now write and run their own workflows

Anthropic's hosted agents can plan a big job, split it across many helper agents, and hand back one combined answer.

The Gayzette · Wonder ◆◆◆◆◇

On October 9, Anthropic released "dynamic workflows" for Claude Managed Agents, its hosted agents that run on Anthropic's servers instead of your laptop. It is in beta, meaning still being tested. An agent can now write a workflow, which is a small program that runs many agents in phases and then combines their results. The target is large jobs, such as reviewing hundreds of documents.

The server runs the workflow in the background as a "workflow run," so nobody has to sit and watch it. To turn it on, you set the agent's multiagent field to {"type":"multiagent_20261001","workflows":{"type":"enabled"}}, use the beta header managed-agents-2026-04-01, and tell the agent in its system prompt (the standing instructions it reads first) when to start a run. You follow progress through workflow_run.* events on the session event stream, which is a live feed of what the agent is doing.

On your desk: any fan-out job, meaning one task repeated across a big pile. Think of tagging a season of Travis Wall Studio class clips, summarizing a month of Plaud transcripts, or cleaning up vault notes. Today that is an n8n loop or a Claude Code session you babysit. This could become one hosted agent you hand the pile to, and the Gayzette's own scouts could fan out the same way.

Claude Code 2.1.295 and 2.1.296 let hooks fail safe

Claude Code shipped two updates, 2.1.295 on October 8 and 2.1.296 on October 9. The headline in 2.1.295 is onFailure: "block" for command and HTTP hooks. A hook is a small script that runs when Claude Code does something. With this setting, if the hook fails to start, times out or exits unexpectedly, the action is blocked instead of going ahead. It also adds 97 fixes.

Version 2.1.296 adds CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL, which runs all workflow agents on one chosen model, plus an allow_large option for the Read tool. The MCP tool description limit rises from 2,048 to 4,096 characters. Cost tracking now reflects Sonnet 5.5 cache reads at $0.10 per million tokens.

On your desk: if any of your automation hooks guard something you care about, such as the vault or the studio's files, add onFailure: "block" so a broken hook stops the action instead of waving it through.

More in AI

Codex now suggests your next message, and you press Tab

Read the brief

OpenAI released composer predictions in Codex on October 9, as a beta. The composer is the box where you type your message. Codex reads the current thread and suggests what you might say next. You press Tab to accept it, then review or edit it. Nothing is sent automatically.

It is for personal ChatGPT Pro users aged 18 and up in the latest Codex desktop app. It works on local and SSH threads (SSH means a connection to another computer) using GPT-6 Astra or GPT-6.1 Sol, and it is on by default. During the beta, generating predictions does not count toward usage limits or credits.

On your desk: this is a small speed-up, and only if you pay for Pro and use Codex alongside Claude Code. If you do, reread each suggestion before accepting, since Tab is easy to hit.

Gemini API retires its old Deep Research agent on October 23

Read the brief

Google posted deprecations to the Gemini API on October 8. A deprecation is a notice that an older model is being retired. gemini-3.7-flash is replaced by gemini-3.8-flash, and gemini-3.5-flash is replaced by gemini-3.6-flash. Both old names are auto-routed to the new model, but you should still update the model string, which is the name your code sends to say which model to use.

The bigger one has a date: deep-research-pro-preview-12-2025 will be shut down on October 23, 2026. Google says to move to deep-research-preview-04-2026 or deep-research-max-preview-04-2026 by changing the agent parameter in interactions.create requests.

On your desk: search your n8n flows for any Gemini node or HTTP call that names the old Deep Research agent or the older flash models. If one does, swap the string before October 23, or that flow will simply stop working.
